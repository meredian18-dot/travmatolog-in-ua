# Developer handover request

Please provide or document the following before migration.

- [ ] Tech stack and versions (framework/CMS, PHP/Node/runtime, database)
- [ ] Full original source repository with history if available; asset files and fonts only where licensed for transfer
- [ ] Current host and build/deploy steps; domains, environments and application routes
- [ ] Dependency manifests and lock files; required environment variable **names** (secrets via secure channel, never in Git)
- [ ] CMS access, content export, database schema/export if applicable; plugin and license requirements
- [ ] Forms, email delivery, CRM/integration dependencies and third-party services
- [ ] All supported languages, translation workflow, routes, redirects, sitemap, robots, canonical/hreflang settings
- [ ] DNS zone records (A/AAAA/CNAME/MX/TXT incl. SPF/DKIM/DMARC) and SSL configuration
- [ ] GA4, Search Console, Tag Manager and Google Business Profile ownership details if used
- [ ] Backup and rollback process
- [ ] Any copyrighted/licensed components or non-transferable dependencies

Do not send passwords through GitHub issues or commit them. Provide secure access separately.
